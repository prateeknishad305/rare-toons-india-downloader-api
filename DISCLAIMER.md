## About this repository

This repository contains **only**:

1. The source code of the Rare Toons India downloader API (a WordPress plugin and a standalone
   PHP front controller) that reads the public catalogue of **rareanimes.foo** and resolves
   download links to their final third-party file-host URLs.
2. A small set of **still screenshots** taken from episodes, kept under `media/` purely as
   visual proof that the API successfully resolves and returns playable media.

**Rare Toons India does not own, host, or distribute the episode files.** The site is an
index: posts link to third-party file hosts (HubCloud, Pixeldrain, GoFile, MEGA, Argon and
similar). This repository does not contain, mirror, re-upload, torrent, or otherwise
redistribute any episode, video file, subtitle, or audio track.
