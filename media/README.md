# media/

This folder holds a single file.

## `preview.jpg`

A 2×2 grid of still frames captured from two episodes that were downloaded through this API
during testing of the resolver:

* Naruto Season 1 Episode 1 (original series, Hindi dub) — `Naruto S01E01 [RareToonsIndia].mkv`
* Naruto Shippuden Season 1 Episode 1 (Hindi dub) — `Naruto Shippuden S01E01 in Hindi.mkv`

The stills were taken from the episode files themselves while verifying that the resolver returns
playable media, and they are published as visual proof that the resolver works end to end.

**The episode files are not redistributed here.** This repository contains the API source code and
this one image only — no episode, video file, subtitle or audio track is mirrored, re-uploaded or
torrented here. The API returns links to the third-party file hosts that the catalogue already
indexes.
